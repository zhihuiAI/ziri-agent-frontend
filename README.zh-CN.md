# Ziri

**面向企业真实业务执行的企业级 AI Agent 平台**

简体中文 | [English](./README.md)

Ziri 连接企业知识、数据、模型、工具与业务系统，让 AI 不只回答问题，而是在清晰的组织规则和权限边界内完成真实工作。

从一句业务目标出发，Ziri 理解企业上下文、制定执行计划、调用相关系统，在关键环节引入人工确认，并交付可验证、可追溯的任务结果。

[立即体验 Ziri](https://ziri.aisky.online)

## 为什么选择 Ziri

通用 Agent 和工作流工具擅长模型调用、工具连接与任务编排，但企业执行还需要统一的业务口径、有效的知识版本、可继承的权限、明确的审批规则，以及能够证明任务正确完成的过程记录。

Ziri 在企业任务与底层 AI 能力之间提供统一、可治理的执行层，帮助企业把分散的工具组织成可持续复用的 AI 生产系统。

## 核心能力

### 目标驱动执行

员工只需说明希望完成什么工作。Ziri 自动拆解任务，识别所需知识与系统，持续执行并根据完成标准检查结果。

### 企业上下文理解

将人员身份、组织角色、业务对象、指标口径、知识版本、数据关系与权限边界组合成一致的任务上下文。

### 知识与系统连接

通过工作流、API 与兼容的集成网关，连接企业知识、数据、工具以及 ERP、CRM、OA/DMS、MES 等业务系统。

### 可信执行

在任务过程中保留知识来源、版本状态、系统调用、校验结果、人工审批与最终交付。高风险动作可以进入确认或审批环节，而不是直接自动执行。

### 业务 Agent 与数字员工

面向具体岗位、流程和行业场景配置可复用的业务 Agent，将已经验证的任务方法沉淀为团队可以安全共享的数字化执行流程。

### 企业 AI 治理

统一管理人员、知识、数据、工具、模型与 Agent 的访问权限，并持续观察执行质量、人工介入、成本、效率和业务结果。

### 灵活部署与模型接入

可根据企业基础设施与安全要求，提供 SaaS、专属环境及私有化部署方案；具体方案可接入公有、私有与本地部署模型。

## Ziri 如何完成任务

1. **理解任务**：识别业务目标、任务对象、执行规则与完成标准。
2. **制定计划**：拆解执行步骤，确定所需数据、知识、工具和系统。
3. **调用系统**：读取信息、调用工具、执行操作并记录全过程。
4. **人工把关**：将敏感或高风险动作提交确认与审批。
5. **验证交付**：核对业务结果，输出可复核的交付物与可追溯记录。

## 典型场景

- **财务任务**：银行对账、回款核销、费用审核、经营分析与月结检查。
- **销售任务**：客户研究、拜访准备、商机跟进与 CRM 记录更新。
- **质量与合规**：SOP 检查、法规比对、风险识别与整改事项跟踪。
- **研发与知识**：文献研究、技术资料分析、项目知识整理与报告生成。
- **人力资源**：简历筛选、面试准备、人才盘点与培训材料整理。
- **日常运营**：数据汇总、流程提醒、跨部门协同与运营报告生成。

## 平台架构

Ziri 将企业 AI 能力组织为五个相互连接的层级：

1. **统一入口**：Web、桌面端与企业协作平台。
2. **AI 工作空间**：专家 Agent、业务 Agent 与个人 Agent。
3. **企业上下文**：知识、数据、记忆、身份与权限。
4. **Agent 运行层**：工作流、评估、模型接入与 API/MCP 集成。
5. **企业系统**：ERP、CRM、OA/DMS、MES 及其他业务应用。

治理能力贯穿所有层级，覆盖权限、审计、安全、成本、效果与业务价值。
